Fortran との対応表

Fortran で書いていた処理を、C++ と MISO でどう書くかを引くための表です。 左の列で Fortran の書き方を探し、右の列の書き方と、説明している章へ進んでください。 表の対応は「同じ目的に使う書き方」の対応で、意味が完全に同じとは限りません。違いがある行には注意を書いています。 ソースのパスは、MISO を clone したフォルダからの相対パスです。

5.3 メモリ上の並び

Fortran は最初の添字が連続（列優先、column-major）、MISO の Array3D は最後の添字が連続（行優先、row-major）です。 同じ a(i, j, k) と書いても、メモリ上で隣にある要素が違います。

Fortran の a(i, j, k)

MISO の a(i, j, k)

メモリ上で隣の要素

a(i+1, j, k)

a(i, j, k+1)

速く回すループ（最も内側）

i

k

要素の位置（a(nx, ny, nz)）

i + nx*(j + ny*k)（0 始まりに直した場合）

(i*ny + j)*nz + k

次の短いプログラムは、MISO の Array3D で要素がメモリの先頭から何番目にあるかを表示します（説明用の例）。

// order.cpp: Array3D のメモリ上の並びを確かめる
#include <iostream>

#include <miso/array3d.hpp>

int main() {
  miso::Array3D<double> a(2, 3, 4);  // a(i, j, k): i < 2, j < 3, k < 4
  const double *p = a.data();       // 先頭の要素のアドレス
  // 要素のアドレスと先頭のアドレスの差 = 先頭から何番目か
  std::cout << "a(0,0,1): " << &a(0, 0, 1) - p << "\n";
  std::cout << "a(0,1,0): " << &a(0, 1, 0) - p << "\n";
  std::cout << "a(1,0,0): " << &a(1, 0, 0) - p << "\n";
  std::cout << "a(1,2,3): " << &a(1, 2, 3) - p << "\n";
}

a(0,0,1): 1
a(0,1,0): 4
a(1,0,0): 12
a(1,2,3): 23

k を 1 増やすと隣（1 番目）、j を 1 増やすと 4 個先、i を 1 増やすと \(3 \times 4 = 12\) 個先です。 Fortran で同じ大きさの配列 a(2, 3, 4) を作ると、a(2, 1, 1) が先頭から 2 番目（1 始まり）になり、i の方向が連続します。 MISO の出力ファイル（mhd/mhd.*.bin）もこの並びで書かれるので、Fortran や NumPy で読むときは添字の順に注意します。
