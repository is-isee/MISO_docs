読み方の基本：宣言か式か

C++ では、同じ記号が宣言（新しい名前を作る文）と式（すでにある名前を使う計算）で別の意味になります。 記号に迷ったら、まずその行が名前を作っているのか、使っているのかを確かめます。

double a = 1.0;
double *p = &a;  // 宣言の * : p は「double を指すポインタ」。式の & : a のアドレス
*p = 2.0;        // 式の * : p の指す先（a）に 2.0 を書きます
double &r = a;   // 宣言の & : r は a の別名（参照）

以下の表では、a・b を double の変数、p を double * 型のポインタ、T をテンプレート引数の型として読みます。

第 8 章

宣言を読むときの確認順序

長い宣言は、次の順に分けて読みます。

  1. 名前を見つけます。 変数・関数・型のどれを宣言しているかを確かめます。

  2. 型を読みます。 <...> まで含めて 1 つの型です。template <...> が前にあれば、山括弧の中の名前は後から決まる型です。

  3. 値・参照・ポインタを区別します。 名前に & や * が付いているかを見ます。

  4. const の対象を確かめます。 値、指す先、ポインタ自身、メンバ関数のどれかを区別します。

  5. 作り方と寿命を確かめます。 初期値、引数、戻り値がどの実体を使い、いつまで使えるかを追います。

例として、miso/include/miso/mhd_integrator.hpp の宣言を分けて読みます。

template <typename Real, typename Source>
__host__ __device__ inline Real source_vx(const Source &src,
                                          const FieldsView<const Real> &qq,
                                          int i, int j, int k);

部分

読み方

template <typename Real, typename Source>

Real と Source は後から決まる型です

__host__ __device__

CPU からも GPU からも呼べる関数です

inline

ヘッダに置く関数です

Real source_vx(...)

名前は source_vx、戻り値の型は Real です

const Source &src

ソース項の実体を、読むだけの参照で受け取ります

const FieldsView<const Real> &qq

要素を読むだけの View（FieldsView<const Real>）を、読むだけの参照で受け取ります

int i, int j, int k

格子点の添字を値で受け取ります

文法の詳細は、C++17 規格草案 N4659 の 参照の宣言、 const の規則、 テンプレートで確認できます。
