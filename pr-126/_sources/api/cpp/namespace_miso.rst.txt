Namespace miso
==============


Radiative Transfer (RT) module for CPU. 




.. contents:: Contents
   :local:
   :backlinks: none




Detailed Description
--------------------

Angular quadrature for radiative transfer calculations.

Implements a monochromatic RT solver for CPU-based simulations.
