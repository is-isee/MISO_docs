Class Documentation

template<class T, class Backend>
class UniformTableInterpolator2D

Interpolator for 2D (x0, x1) table in the uniform grid.

The table is assumed to be uniformly spaced, i.e., x0[i] = x0_min + i * dx0, x1[j] = x1_min + j * dx1. Value is linearly interpolated between the two nearest table entries. If (x0, x1) is out of the table range, the nearest table value is returned.
