Basics of reading: declaration or expression?

In C++, the same symbol means different things in a declaration (a statement that creates a new name) and in an expression (a computation that uses an existing name). When you are unsure about a symbol, first check whether the line is creating a name or using one.

double a = 1.0;
double *p = &a;  // * in a declaration: p is a "pointer to double". & in an expression: address of a
*p = 2.0;        // * in an expression: write 2.0 to what p points to (a)
double &r = a;   // & in a declaration: r is an alias (reference) of a

In the tables below, read a and b as double variables, p as a pointer of type double *, and T as a template argument type.

Chapter 8

Order of checks when reading a declaration

Read a long declaration by splitting it up in the following order.

  1. Find the name. Check whether it declares a variable, a function, or a type.

  2. Read the type. The type includes everything up to <...>. If template <...> comes before, the names inside the angle brackets are types decided later.

  3. Distinguish value, reference, and pointer. Look at whether & or * is attached to the name.

  4. Check what const applies to. Distinguish whether it is the value, what is pointed to, the pointer itself, or the member function.

  5. Check how it is created and its lifetime. Trace which objects the initial value, parameters, and return value use, and how long they remain usable.

As an example, let us read a declaration from miso/include/miso/mhd_integrator.hpp in parts.

template <typename Real, typename Source>
__host__ __device__ inline Real source_vx(const Source &src,
                                          const FieldsView<const Real> &qq,
                                          int i, int j, int k);

Part

How to read it

template <typename Real, typename Source>

Real and Source are types decided later

__host__ __device__

A function that can be called from both the CPU and the GPU

inline

A function placed in a header

Real source_vx(...)

The name is source_vx and the return type is Real

const Source &src

Receives the source-term object as a reference for reading only

const FieldsView<const Real> &qq

Receives a view that only reads the elements (FieldsView<const Real>) as a reference for reading only

int i, int j, int k

Receives the grid-point indices by value

For the details of the grammar, see the C++17 draft standard N4659: declaring references, the rules for const, and templates.
